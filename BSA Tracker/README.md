**Objective**

Analyze debt settlement performance across collection agencies, account types, and recovery programs to identify opportunities for improving collection effectiveness and reducing losses.

**Tools Used**

Excel
Pivot Tables
SQL
Charts
Trend Analysis

**Analysis Performed**

Settlement performance by collection agency
Average settlement percentage analysis
Settlement amount and forgiveness amount tracking
Number of payments required to settle accounts
Recovery performance by account type
Monthly settlement trend analysis
Agency performance comparison

**Key Insights**

Identified agencies achieving the highest recovery rates
Measured average settlement percentages across vendors
Evaluated account settlement trends over time
Analyzed forgiveness amounts and recovery effectiveness
Tracked settlement completion activity and account resolution performance
Highlighted opportunities to improve collection outcomes

**Skills Demonstrated**

Data Cleaning
Data Analysis
KPI Reporting
Vendor Performance Analysis
Financial Analytics
Trend Analysis
Data Visualization
Business Reporting

**Business Impact**

This analysis provided visibility into collection agency performance and settlement effectiveness, helping stakeholders evaluate recovery strategies and identify opportunities to maximize recoveries while managing delinquent accounts.
